# 电子斗蛐蛐

一个桌面浏览器优先的全自动自由混战模拟器。项目使用 React、TypeScript、Phaser
和 60Hz 固定步长战斗内核，支持自定义角色、动作帧、音效、棋盘背景与范围道具。

## 已内置

- 熊猫：吃竹子回血；作为保护动物，受敌方攻击后会有一星人类警察赶来保护。
- 五级人类警察：警棍、手枪、步枪三连发、RPG、加特林与踹击。
- 地鼠：挖洞、洞口偷袭、随机地道移动、洞口踩平与死亡清理。
- 竹林熔岩竞技场：六处竹子、三片岩浆、四角安全出生区。
- 赛前编队、自动战斗、暂停/单步、0.5–4 倍速、同种子或新种子重开。
- IndexedDB 自动保存、JSON 配置往返、带素材的 ZIP 分享包。
- 图片/动作帧/音效上传，以及纯色背景去除和程序合成默认音效。

## 本地运行

```bash
npm install
npm run dev
```

生产校验：

```bash
npm test
npm run build
```

默认页面地址为 `http://localhost:3000/`。
