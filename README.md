# 电子斗蛐蛐

一个桌面浏览器优先的全自动自由混战模拟器。项目使用 React、TypeScript、Phaser
和 60Hz 固定步长战斗内核，支持自定义角色、动作帧、音效、棋盘背景与范围道具。

## 已内置

- 懒洋洋但清醒的熊猫：躺着吃竹子回血；作为保护动物，受敌方攻击后会有一星人类警察赶来保护。旧版活力熊猫保留为可替换皮肤。
- 五级人类警察：警棍、手枪、步枪三连发、RPG、加特林与踹击；同星警察必须在棋盘上相撞才会升星。
- 地鼠：挖洞、跨归属通用洞口偷袭、随机地道移动、专属钻洞攻击动作；洞口默认被重新踩中三次后才消失。
- 竹林、横屏直播与手机竖屏三张棋盘；包含可编辑的竹子、岩浆燃烧区和温泉回血区。
- 岩浆和温泉提供离开区域后仍持续三秒的 Buff；形状、边界、范围、持续时间和每秒数值均可编辑。
- 赛前编队、自动战斗、暂停/单步、0.5–4 倍速、同种子或新种子重开。
- 纯净全屏观战（快捷键 `F`），隐藏编辑组件并保持棋盘比例，便于直播或录屏软件捕捉。
- IndexedDB 自动保存、JSON 配置往返、带素材的 ZIP 分享包。
- 图片/动作帧/音效上传、搞笑随机台词/动物叫声、纯色背景去除和程序合成默认音效。
- 血条实时数值、燃烧/温泉状态、扣血与回血飘字；棋盘角色比例与全部内置技能参数可调。

## 本地运行

```bash
npm install
npm run dev
```

生产校验：

```bash
npm test
npm run build
```

默认页面地址为 `http://localhost:3000/`。
