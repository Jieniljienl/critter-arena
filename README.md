# 电子斗蛐蛐

一个桌面浏览器优先的全自动自由混战模拟器。项目使用 React、TypeScript、Phaser
和 60Hz 固定步长战斗内核，支持自定义角色、动作帧、音效、棋盘背景与范围道具。

## 已内置

- 懒洋洋但清醒的熊猫：躺着吃竹子回血，场上存在熊猫时每 15 秒补充一份竹子（默认上限 3）；受到直接攻击会举起 SOS 并呼叫一星人类警察。
- 六星人类警察体系：警员可通过同阵营碰撞或个人击杀积累经验升星；五星为狙击手，六星为重装无畏战士。
- 地鼠：挖洞、跨归属通用洞口偷袭、随机地道移动、专属钻洞攻击动作；洞口不会被经过的角色踩平。
- 六张内置棋盘：竹林熔岩竞技场、横屏直播竞技场、手机竖屏直播竞技场、月夜观星台、赤砂绿洲与极光冰湖；包含可编辑的竹子、岩浆燃烧区和温泉回血区。
- 岩浆和温泉提供离开区域后仍持续三秒的 Buff；形状、边界、范围、持续时间和每秒数值均可编辑。
- 赛前编队、自动战斗、暂停/单步、0.5–4 倍速、同种子或新种子重开。
- 纯净全屏观战（快捷键 `F`），隐藏编辑组件并保持棋盘比例，便于直播或录屏软件捕捉。
- IndexedDB 自动保存、JSON 配置往返、带素材的 ZIP 分享包。
- 图片/动作帧/音效上传、仅在对应技能触发时播放的可编辑专属台词、动物叫声、纯色背景去除和程序合成默认音效。
- 警察血条下方显示分星经验格，六星无畏战士改为显示实时弹量和换弹状态；默认结算姿势至少使用两张不同动作帧。
- 近战只在接近目标且目标处于正面扇区时出手，默认接触距离已适度放宽；所有角色的普攻范围都可在角色工坊独立修改并随配置导入导出。RPG 默认飞行 1.5 秒后提速至 1.5 倍，角色阵亡不会清除已经发射的弹丸。
- 血条实时数值、燃烧/温泉状态、扣血与回血飘字；棋盘角色比例与全部内置技能参数可调。

### 警察星级

| 星级 | 角色 | 默认能力 |
| --- | --- | --- |
| 一星 | 巡逻警员 | 警棍近身压制 |
| 二星 | 手枪警员 | 手枪全图弹道 |
| 三星 | 步枪警员 | 步枪三连发 |
| 四星 | 火箭警员 | RPG 范围爆破 |
| 五星 | 狙击手 | 蹲伏瞄准 3 秒并显示红色引导线，随后发射高速狙击弹；默认伤害 60、偏离概率 12% |
| 六星 | 重装无畏战士 | 加特林定向周期连发；默认 150 发弹仓、3 秒换弹，并可近身踹飞敌人、在撞墙时追加眩晕 |

上述技能数值均可在角色工坊中调整。

## 本地运行

```bash
npm install
npm run dev
```

生产校验：

```bash
npm test
npm run build
```

默认页面地址为 `http://localhost:3000/`。
